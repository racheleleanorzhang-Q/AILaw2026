# AILaw2026 Prototype

面向中国律所业务管理场景的 AI 业务管理系统原型，围绕商机、客户、合同、项目、工时、财务和结项形成完整业务链路。

## 当前正式基线

- 正式版本：V3.0
- 正式原型：[prototype-v3.0.html](./prototype-v3.0.html)
- 在线地址：https://racheleleanorzhang-q.github.io/AILaw2026/prototype-v3.0.html
- 基线说明：[WENSEN_AI_V3.0_BASELINE.md](./WENSEN_AI_V3.0_BASELINE.md)

后续设计和开发必须以 V3.0 为基础，不回退到 V1.x 或 V2.0-V2.5 的旧产品结构。

## 设计原则

- 不做泛 OA，围绕律所业务从商机到项目结项的主链路设计。
- 同一业务对象只保留一个权威数据源，不在不同菜单重复建立台账。
- 列表负责检索、筛选和操作，详情页负责完整信息与关联关系。
- 审批、客户、报价、合同、项目、工时和财务记录必须通过业务对象关联，不允许形成孤立数据。
- 业务状态决定可执行操作，未满足前置条件时不得提前进入后续正式流程。
- 原型采用纯静态 HTML，并通过 GitHub Pages 发布关键版本。

## 已确认的核心业务链路

```text
业务线索与报价
  → 客户确认合作
  → 从商机发起合同
  → 客户准入及利益冲突复核
  → 合同内容、收费及项目安排审批
  → 完成签署并上传双签版
  → AI 核验双签版
  → 系统自动生成正式项目
  → 项目执行产生工作记录和工时数据
  → 生成项目应收计划
  → 开票、回款及应收核销
  → 项目结项审批
  → 自动归档并形成项目档案和结项报告
```

## V3.0 本轮新增

### 1. 工作台

- 工作台首页新增【我的工时】常驻模块，作为个人每日高频入口。
- 【我的工时】展示今日已记录、本周已记录、正在计时和快速记录。
- 【我的待办】中，已立项项目任务自动展示【记录工时】和【查看工作记录】。
- 商务跟进任务不默认展示工时入口，仍归入商机阶段的跟进任务和跟进记录。
- 工作台快速记录工时后，数据同步进入对应项目的【工作记录】和全局【工时管理】。

### 2. 项目管理

- 【工时管理】新增在【项目管理】模块下。
- 【已立项管理】中的项目详情继续保留【工作记录】Tab。
- 【工作记录】定位为单个项目的执行日志，记录项目立项后的具体工作、说明、成果和耗时。
- 【工时管理】定位为跨项目工时台账与统计中心，汇总所有项目工作记录中的工时数据。
- 两个入口写入同一套数据：从项目详情新增自动带入当前项目，从工时管理新增需要先选择项目。

### 3. 工作记录

- 记录工作只覆盖合同签署后、项目立项后的正常执行过程。
- 工作类型限定为项目执行工作类型，包括项目会议、材料接收与整理、材料审阅、法律研究、合同/文件审阅、文书起草、文件修改、客户执行沟通、对外沟通/协调、成果交付、项目管理/进度推进。
- 工作记录表单包含工作事项、工作类型、执行人、发生时间、耗时、工作说明、相关文件/成果、是否计入项目工时。
- 商务沟通、销售跟进和签约推进不进入项目工作记录，仍属于商机与合同签署前流程。

### 4. 工时管理

- 工时不需要审批，不设置草稿、待确认、已确认、已退回、已锁定等状态。
- 工时保存后即进入统计、筛选和导出。
- 工时管理列表字段包括日期、项目、客户、执行人、工作类型、工作事项和工时。
- 工时管理支持我的工时记录、项目工时汇总、客户工时汇总、常法工时消耗、人员工时统计、筛选和导出。
- 工时数据后续服务于财务统计、成本分析、常法额度消耗、结项复盘和同类项目报价参考。

### 5. 数据中心

- 数据中心在 V3.0 纳入工时数据层。
- 客户、商机、合同、项目、工时、财务和结项数据应按统一业务对象关联。
- 工时指标不作为审批结果，而作为项目投入、服务消耗、成本和利用率的经营数据。

## V2.5 已确认的核心产品结构

### 1. 商机与报价

- 【业务线索】与【报价台账】合并为【商机与报价】，报价台账不再作为独立菜单。
- 商机详情采用【商机信息】【报价明细】【跟进记录】三个 Tab。
- 客户确认合作、最终报价已确认且报价审批通过后，商机操作中才出现【发起合同】。
- 合同不能脱离客户、商机和最终报价直接创建。

### 2. 客户与利益冲突

- 客户列表和创建商机时的新建客户共用同一个【新增客户】模块。
- 新增客户必须进行利益冲突检查并进入客户准入审批。
- 审批中的客户允许保存商机草稿，但禁止正式报价、合同和项目等后续工作。

### 3. 跟进任务与跟进记录

- 跟进记录是可复用的独立业务模块，在商机详情、跟进任务等入口共享同一份数据。
- 跟进任务与商机阶段绑定，可在完成跟进时更新商机阶段。
- 商机进入【客户确认合作】后，才开放合同相关操作。

### 4. 流程审批

- 审批中心下只保留【流程审批】一个菜单。
- 页面分为【待我审批】和【我的申请】两个主 Tab。
- 同意与拒绝均弹出审批意见输入框；拒绝意见必填，同意意见选填。

### 5. 项目管理

- 原【项目承接申请】改为【项目清单】。
- 原【项目台账】改为【已立项管理】，项目执行能力放入项目详情。
- 原【项目归档】改为【已归档项目】。
- 标准合同项目的客户、收费和项目安排随合同一并审批，双签版核验通过后自动生成正式项目。
- 项目详情包括项目概览、执行计划、工作记录、文件与成果、合同与变更、项目动态。
- 工作记录支持记录工作内容和工时，并统计项目总工时。
- 项目结项必须满足工作及成果完成、工时核对、文件完整且全部应收款收回。

### 6. 合同管理

- 合同台账、合同签署、合同修改/作废和合同归档合并为【合同管理】。
- 合同附件统一放入详情页，支持在线查看。
- 合同变更、作废和归档只能从具体合同操作中发起，并进入合同审批流程。
- 【合同管理】不提供全局【发起合同审批】按钮；合同审批只能从符合条件的商机发起。

### 7. 应收、开票与回款

- 【应收计划】用于客户应向律所支付的项目合同款。
- 只有双签版核验通过并正式生成项目后，系统才按合同结算条件生成一笔或多笔应收计划。
- 开票由项目负责人申请、办公室主任审批、财务开具并上传。
- 回款由财务登记、办公室主任确认，系统自动核销应收并更新项目付款进度。
- 最后一笔回款完成后，系统提醒项目负责人发起结项。

### 8. 数据与经营输出

- 数据中心按客户汇集合同、项目、应收、开票、回款和结项档案。
- 经营中心汇总收入、成本、利润、人员投入、客户满意度、回款周期和项目执行效果。
- 结项数据应为后续报价、人员安排和同类业务管理提供参考。

## 下一轮讨论范围

下一轮对话以 V3.0 为基础，重点继续细化：

1. 【数据中心】：客户、商机、合同、项目、工时、财务和结项数据的指标口径；
2. 【工时管理】：常法额度、项目成本、人员投入和导出计时单的展示细节；
3. 【工作台】：不同角色看到的待办、提醒、风险和经营概览。
