# AILaw2026 Prototype

面向中国律所业务管理 SaaS 的法律业务审批模块原型。

## 页面范围

- 工作台总览
- 审批中心
- 审批详情
- 发起审批
- 模板配置
- 规则配置
- 治理报表

## 设计目标

- 参考 Alpha 风格的整体信息架构与视觉节奏
- 不做泛 OA，而是围绕法律业务审批主链路
- 用纯静态页面部署到 GitHub Pages

## 本次原型聚焦

Phase 1 审批对象：

1. 新客户准入审批
2. 利益冲突审批
3. 新项目立项审批
4. 报价审批
5. 折扣/减免审批
6. 合同条款偏离审批
7. 对外法律意见/正式文书审批
8. 开票申请审批

## 原型重要版本记录
1. V1.0 完成 工作台 和 线索与客户管理的功能设计
2. V1.7 完成 项目管理 的功能设计
3. V2.0 梳理 线索-客户-合同-项目的关系
4. V2.1 合并合同台账、签署、变更、作废与归档，形成统一合同管理
5. V2.2 增加完整合同详情抽屉，分组展示业务、结算、团队、文件、AI 核验与审批信息
6. V2.3 收敛合同查看、状态解释与业务操作入口，合同详情保持只读
7. V2.4 打通合同应收、开票、回款与项目结项审批，区分对外付款和项目应收
8. V2.5 收紧合同审批唯一入口，项目正式生成后才建立应收、开票和回款台账
