# AILaw2026 Prototype

面向中国律所业务管理 SaaS 的法律业务审批模块原型。

## 页面范围

- 工作台总览
- 审批中心
- 审批详情
- 发起审批
- 模板配置
- 规则配置
- 治理报表

## 设计目标

- 参考 Alpha 风格的整体信息架构与视觉节奏
- 不做泛 OA，而是围绕法律业务审批主链路
- 用纯静态页面部署到 GitHub Pages

## 本次原型聚焦

Phase 1 审批对象：

1. 新客户准入审批
2. 利益冲突审批
3. 新项目立项审批
4. 报价审批
5. 折扣/减免审批
6. 合同条款偏离审批
7. 对外法律意见/正式文书审批
8. 开票申请审批
