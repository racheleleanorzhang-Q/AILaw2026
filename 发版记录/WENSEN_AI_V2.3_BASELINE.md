# 文森 AI 管理系统 V2.3 正式基线

## 1. 版本定位

V2.3 以 V2.2 的完整合同详情为基础，收敛合同查看、状态解释和业务操作入口。

正式原型：`prototype-v2.3.html`

## 2. 三类入口的职责

- 【查看】：打开完整合同详情，只负责信息查看。
- 状态标签：解释合同状态或 AI 核验异常，可打开对应差异信息。
- 【操作】：承载上传、重新上传、变更、作废、归档等业务动作。

同一业务动作不得同时出现在合同详情、差异页和操作列中。

## 3. 合同详情

- 合同名称和操作列中的【查看】打开同一个合同详情抽屉。
- 【合同概览】按合同基本信息、合同内容概述、合同附件、关联关系的顺序展示。
- 合同附件包括审批版本和双签版/扫描件，支持在线查看及下载。
- 【文件与 AI 核验】继续展示文件版本和核验结果，但不提供上传、重新上传或变更操作。
- 详情底部只保留【关闭】和【导出合同信息】。
- 详情中不提供【发起变更】【发起作废】【上传双签版】或独立的【查看差异】按钮。

## 4. 差异查看

- 当合同存在实质差异时，【合同状态：发现差异】和【AI 核验：发现实质差异】均可点击。
- 详情中【AI 核验结果：发现实质差异】同样可进入版本差异页。
- 所有入口打开同一个只读差异页，展示审批通过版本、双签版本、差异字段和 AI 判断。
- 差异页底部只保留【关闭】，不提供【重新上传】或【发起合同变更】。

## 5. 操作列规则

| 合同状态 | 主要操作 |
| --- | --- |
| 草稿 | 查看、编辑、提交审批 |
| 审批中 | 查看、查看审批 |
| 待双签 | 查看、上传双签版、作废 |
| 已上传待核验 | 查看、开始 AI 核验 |
| 发现差异 | 查看、重新上传、发起变更 |
| 已签署 | 查看、发起变更、发起作废、归档 |
| 已作废 | 查看 |
| 已归档 | 查看 |

操作列不再提供【查看文件】或【查看差异】；查看文件统一进入合同详情，查看差异统一点击状态标签。

## 6. 继承原则

- 继续沿用 V2.2 的六标签合同详情、合同签约快照、结算明细、团队分工、审批记录及上下条切换。
- 继续沿用 V2.1 的统一合同数据源、合同状态与归档状态分离、关联台账精准跳转规则。
- 合同变更和作废仍必须进入流程审批，不允许直接覆盖已生效合同。
