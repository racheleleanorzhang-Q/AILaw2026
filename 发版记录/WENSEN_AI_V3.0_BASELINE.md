# WENSEN AI V3.0 BASELINE

## 版本定位

V3.0 在 V2.5 正式基线之上，补充工作台、工时管理和数据中心的产品结构。

V2.5 已确认的主链路不变：

```text
商机 → 客户 → 合同 → 项目 → 财务 → 结项
```

V3.0 新增：

```text
项目执行 → 工作记录 → 工时台账 → 统计导出 / 财务成本 / 结项复盘
```

## 一、工作台

工作台首页新增【我的工时】常驻模块，作为个人每日高频入口。

包含：

- 今日已记录工时
- 本周已记录工时
- 正在计时任务
- 快速记录工时

【我的待办】中，已立项项目任务自动展示：

- 记录工时
- 查看工作记录

商务跟进任务不自动展示工时入口，仍归入商机阶段的跟进任务和跟进记录。

## 二、项目管理与工时管理

【工时管理】新增在【项目管理】模块下。

项目管理下形成两层视角：

```text
已立项管理 / 项目详情 / 工作记录
  = 单个项目的执行日志

项目管理 / 工时管理
  = 跨项目工时台账与统计中心
```

两者使用同一套数据，不建立两套记录。

从项目详情新增工作记录时，系统自动带入当前项目。

从工时管理新增工时时，需要先选择项目。

保存后，两处同步展示。

## 三、工作记录

工作记录只覆盖合同签署后、项目立项后的正常执行过程。

不包含：

- 商务沟通
- 销售跟进
- 签约推进

上述内容仍属于商机阶段的跟进任务和跟进记录。

工作记录表单字段：

- 工作事项
- 工作类型
- 执行人
- 发生时间
- 耗时
- 工作说明
- 相关文件 / 成果
- 是否计入项目工时

工作类型限定为项目执行类型：

- 项目会议
- 材料接收与整理
- 材料审阅
- 法律研究
- 合同 / 文件审阅
- 文书起草
- 文件修改
- 客户执行沟通
- 对外沟通 / 协调
- 成果交付
- 项目管理 / 进度推进

## 四、工时管理

工时不需要审批。

因此不设置：

- 草稿
- 待确认
- 已确认
- 已退回
- 已锁定

工时保存后即进入统计、筛选和导出。

工时管理列表字段：

- 日期
- 项目
- 客户
- 执行人
- 工作类型
- 工作事项
- 工时

工时管理支持：

- 我的工时记录
- 项目工时汇总
- 客户工时汇总
- 常法工时消耗
- 人员工时统计
- 按项目 / 客户 / 人员 / 日期 / 工作类型筛选
- 导出工时明细
- 导出项目计时单

## 五、数据中心

V3.0 将工时纳入数据中心。

工时不是审批结果，而是经营数据。

工时数据用于：

- 项目投入统计
- 常法额度消耗
- 人员利用率
- 项目成本分析
- 结项复盘
- 同类项目报价参考

数据中心应继续围绕统一业务对象汇集：

- 客户
- 商机
- 合同
- 项目
- 工时
- 应收
- 开票
- 回款
- 结项档案

## 六、后续基线要求

后续设计和开发必须以 V3.0 为基础。

不得回退到：

- 工时需要审批的状态设计
- 将商务跟进混入项目工作记录
- 工作记录和工时管理各建一套数据
- 将工时管理放成脱离项目管理的孤立模块
